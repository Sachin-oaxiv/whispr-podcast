# Whispr — Podcast Website

Independent React + Vite frontend project.

## Run it
```bash
npm install
npm run dev
```

## Voice preview
The episode Play buttons use your browser's built-in speech synthesis to read a short spoken preview. It does not stream a full 28–41 minute podcast recording, and the voice depends on the voices installed in your browser/device. If you hear nothing, check system/browser volume and try a current version of Chrome, Edge, or Safari.

## Production build
```bash
npm run build
```

## Notes
- Each website has its own folder and package.json.
- Episode voice previews are generated by browser text-to-speech; there is no external audio hosting or backend.
- Sample photography is loaded from Unsplash, so internet access is needed to display images.
